Official Google Sheets Integration Guide

How To Create Your Google Sheet Backend

Follow these simple steps to link your Google account to your website. Every time a client submits the contact form, their inquiry is instantly added to your spreadsheet.

1 Create a New Google Spreadsheet

1. Open sheets.google.com in your browser.

2. Click on the + Blank spreadsheet button.

3. At the top left, name the spreadsheet: Zudonet Client Inquiries.

4. Make sure the tab at the very bottom is named: Sheet1 (this is default).

2 Set Column Headers in Row 1

In the first row of your spreadsheet (Row 1), type these exact column headers across columns A to H:

Col A Col B Col C Col D Col E Col F Col G Col H
timestamp ticketId name email contact_number service message terms
Important: Keep all header words in lowercase as shown above (name, email, contact_number, etc.) so the script matches them automatically.
3 Open Apps Script in Google Sheets

1. In the top Google Sheets menu, click: Extensions > Apps Script.

2. A new tab will open showing the script editor.

3. Delete any default code like function myFunction() { } so the editor is completely empty.

4 Paste the Backend Script

Copy the script below and paste it into the Apps Script editor:

var sheetName = 'Sheet1';
var scriptProp = PropertiesService.getScriptProperties();

function initialSetup() {
  var activeSpreadsheet = SpreadsheetApp.getActiveSpreadsheet();
  scriptProp.setProperty('key', activeSpreadsheet.getId());
  Logger.log('Connected to Sheet ID: ' + activeSpreadsheet.getId());
}

function intialSetup() {
  initialSetup();
}

function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.tryLock(10000);

  try {
    var doc = SpreadsheetApp.openById(scriptProp.getProperty('key'));
    var sheet = doc.getSheetByName(sheetName);

    var headers = sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0];
    var nextRow = sheet.getLastRow() + 1;

    var data = e.parameter || {};
    if (e.postData && e.postData.contents) {
      try {
        var parsed = JSON.parse(e.postData.contents);
        for (var k in parsed) {
          if (!data[k]) data[k] = parsed[k];
        }
      } catch (err) {}
    }

    var newRow = headers.map(function(header) {
      if (header === 'timestamp') {
        return new Date();
      }
      return data[header] !== undefined ? data[header] : '';
    });

    sheet.getRange(nextRow, 1, 1, newRow.length).setValues([newRow]);

    return ContentService
      .createTextOutput(JSON.stringify({ 'result': 'success', 'row': nextRow }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ 'result': 'error', 'error': err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  } finally {
    lock.releaseLock();
  }
}

Click the Save icon (💾) at the top of Apps Script.

5 Run initialSetup Once

1. In the toolbar at the top of Apps Script, find the dropdown next to "Debug" and select: initialSetup.

2. Click the Run button (▶️).

3. If Google shows "Authorization required":

  • Click Review Permissions.
  • Choose your Google account.
  • Click Advanced (bottom left of modal).
  • Click Go to Untitled project (unsafe).
  • Click Allow.
Once authorized, the script automatically links your spreadsheet key forever!
6 Deploy as a Public Web App

1. At the top right of Apps Script, click the blue Deploy button > New deployment.

2. Click the gear icon (⚙️) next to "Select type" and choose Web app.

3. Configure these exact settings:

  • Description: Zudonet Form API
  • Execute as: Me (your Google email)
  • Who has access: Anyone
Critical Note: "Who has access" MUST be set to Anyone so prospective clients can submit inquiries without being forced to sign into a Google account.

4. Click Deploy.

5. Copy the Web App URL (it starts with https://script.google.com/macros/s/.../exec).

7 Add Your Web App URL to the Website

Open zudonet.js on your Desktop, find line 14:

googleAppsScriptUrl: 'PASTE_YOUR_COPIED_URL_HERE',

Save zudonet.js. Your website is now 100% connected to your personal Google Sheet!
