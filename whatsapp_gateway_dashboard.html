How to Run the Local Gateway Background Server

To receive web inquiries automatically in the background, you can run the standalone python gateway server included right on your Desktop:

python C:\Users\sreej\OneDrive\Desktop\whatsapp_gateway_server.py

When any client fills out the inquiry form on your website (e.g. on contact.html), the site automatically posts to http://localhost:3000/send/message and opens your WhatsApp directly with their ticket details.
